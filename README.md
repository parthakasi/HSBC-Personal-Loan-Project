# HSBC-Personal-Loan-Project

Overview

Analyzed customer data to identify customers who are more likely to take personal loans and created a dashboard to generate business insights.

Tools Used
Microsoft Excel
Pivot Tables
Charts and Dashboard
Work Done
Cleaned and organized the dataset.
Analyzed customer income, education, family size, mortgage, and banking behavior.
Created pivot tables for analysis.
Built charts and graphs for visualization.
Designed an interactive dashboard with insights and recommendations.
Key Findings
Customers with income above 100K take more loans.
Professional and graduate customers have higher loan acceptance.
Families with 3–4 members are strong loan targets.
Existing banking customers are more likely to accept loans.
Customers with lower mortgage values have better repayment capability.
Conclusion

The project helps identify high-potential customers for personal loans and supports better business decision-making through data analysis and visualization.
