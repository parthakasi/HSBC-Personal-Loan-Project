Overview

This project focuses on analyzing customer data to identify customers who are more likely to take personal loans. The analysis was performed to generate business insights and help improve customer targeting strategies through an interactive dashboard.

Tools Used
Microsoft Excel
Pivot Tables
Charts and Graphs
Dashboard Design
Work Done
Cleaned and organized the dataset for analysis.
Analyzed customer attributes such as income, education, family size, mortgage, and banking behavior.
Created pivot tables to summarize and compare customer data.
Built charts and visualizations for better understanding of trends and patterns.
Designed an interactive dashboard with insights and business recommendations.
Key Findings
Customers with income above 100K are more likely to take personal loans.
Professional and graduate customers show higher loan acceptance rates.
Families with 3–4 members are strong target customers for personal loans.
Customers using online banking, TD accounts, securities accounts, and credit cards are more likely to accept loans.
Customers with lower mortgage values have better repayment capability.
Conclusion

The project helps identify high-potential customers for personal loans using customer behavior and financial analysis. The dashboard and insights support better business decision-making, improve customer targeting, and help increase loan conversion rates.
